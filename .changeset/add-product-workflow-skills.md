Add four model-invoked engineering skills that extend the build flow toward product work: `ux-design`, `ui-design`, `test`, and `experiment`.

- `ux-design` turns a spec into a user experience: goals, information architecture, primary and alternative flows, and system states, handing `ui-design` a screen/state map.
- `ui-design` turns that map into an implementation-ready visual system: hierarchy, typography and spacing, reusable components with their states, responsive rules, and design tokens.
- `test` validates a finished change against its acceptance criteria across happy path, failure and edge states, and regressions, before it reaches review.
- `experiment` runs a controlled loop (hypothesis, change, run, measure, compare, keep/reject, record) to decide between alternatives from measured evidence.

All four are promoted `engineering/` skills, so each has a `README.md` reference, a `.claude-plugin/plugin.json` entry, a docs page under `docs/engineering/`, and a route in `ask-matt`.
