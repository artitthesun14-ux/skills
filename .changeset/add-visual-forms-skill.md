Add the `visual-forms` model-invoked productivity skill. It distils content to its core point, reads the relationship in it, and picks the form that shows it fastest (tree, stack or pyramid, flow, system diagram, timeline, matrix, animation, or plain cards), each with a fit test for when to use another form, then writes only what the form cannot carry and discloses the rest in four levels. Accuracy beats polish: no causal arrow without evidence, UNKNOWN in a slot with no data, and text where no form is correct.

It is the one source for these rules: `investment-thesis` pages, `ui-design`, and the in-progress `motion-design`, `visual-prototyping` and `animation-review` call the Skill tool with "visual-forms" instead of restating them. Wired into `.claude-plugin/plugin.json`, the top-level and `productivity/` `README.md` (Model-invoked), a docs page at `docs/productivity/visual-forms.md`, and a route in `ask-matt`.
