# 07: Swap บอกว่าตัวไหน "แนะนำ" ที่สุด

**What to build:** ตอนวนสลับชิ้นในหมวดหนึ่ง พอวนมาเจอตัวที่เข้ากับชุดนี้ดีที่สุด (อันดับ 1 ตามคะแนนเงียบ)
ต้องมีป้าย "แนะนำ" ให้เห็น และผู้ใช้ screen reader ต้องรู้ด้วย

**Blocked by:** None (can start immediately).

**Status:** done (เฟส 4-B)

- [x] ป้าย "แนะนำ" โผล่เฉพาะตอนตัวที่แสดงอยู่คืออันดับ 1 ของวง ไม่ใช่ UI แยกถาวร
- [x] `aria-label` ของปุ่มสลับบอกด้วยว่าตอนนี้คือตัวที่แนะนำ
- [x] ยังไม่กดสลับ = ยังไม่มีป้าย (ไม่ต้องคิดคะแนนทุกหมวดทุกการ์ดตอนเรนเดอร์)
