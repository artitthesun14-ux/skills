# 05: เลิกบังคับโครงสร้าง "บน+ล่าง" (Flexible Outfit Generation)

**What to build:** โหมด "จากตู้ของฉัน" แนะนำชุดได้จากของที่มีจริง โดยไม่บังคับว่าต้องมีเสื้อและกางเกง/กระโปรง
ชุดที่ใช้ได้ = มีอย่างน้อย 2 ชิ้นจาก 2 หมวดต่างกัน (1 ชิ้นต่อหมวดเหมือนเดิม) คนที่มีแค่เสื้อนอกกับรองเท้า
ก็เริ่มได้คำแนะนำทันที และการล็อกสี (FR-5) ใช้สีที่อยู่บนหมวดไหนก็ได้ ไม่จำกัดแค่บน/ล่าง

**Blocked by:** None (can start immediately).

**Status:** done (เฟส 4-A)

- [x] `generateWardrobeBatch()` สุ่มแยกตามหมวดที่มีจริง แทน cross-product บน x ล่าง
- [x] ชุดทุกชุดมี >= 2 ชิ้นจาก 2 หมวดต่างกัน และยังมี 1 ชิ้นต่อหมวด (data model ไม่เปลี่ยน)
- [x] Insufficient Data เปลี่ยนเกณฑ์เป็น "ของไม่ถึง 2 หมวด" พร้อมข้อความที่ไม่เอ่ยชื่อหมวดที่ถูกบังคับ
- [x] FR-5: สีที่ล็อกอยู่หมวดไหนก็ได้; No-match เหลือเฉพาะตอนตู้ไม่มีสีนั้นเลยสักชิ้น
- [x] การ์ดไม่กันช่องว่างให้หมวดที่ชุดนั้นไม่มีของ
- [x] `regress.js` invariant เปลี่ยนจาก "บน+ล่างครบ" เป็น ">= 2 ชิ้น"
- [x] main spec FR-1 AC2 / FR-5 AC1 / §7C แก้ถ้อยคำให้ตรงกับกฎใหม่
- [x] เทสต์ 7 ชุดเขียวหมด
