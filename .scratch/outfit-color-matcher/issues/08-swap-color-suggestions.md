# 08: Swap เสนอสีที่น่าจะเข้ากันเมื่อของในตู้หมดตัวเลือก

**What to build:** พอผู้ใช้กดวนสลับจนครบทุกชิ้นในหมวดนั้นแล้วยังไม่ถูกใจ ระบบเสนอ "สีที่น่าจะเข้ากับชุดนี้เพิ่ม"
ให้ 1-2 สี เป็นข้อมูลเฉยๆ (ไม่เปลี่ยนชุด ไม่ใช่การบอกให้ซื้อ)

**Blocked by:** None (can start immediately).

**Status:** done (เฟส 4-B)

- [x] ฟังก์ชันคิดสีแนะนำใช้ scope แคบ = ดูสีของชิ้นอื่นในชุดนั้น ไม่ใช่สีเด่นทั้งตู้แบบ FR-4
- [x] โผล่เฉพาะหมวดที่ผู้ใช้วนจนครบจริง (ทดลองแบบขึ้นลอยๆ ให้ทุกหมวดที่มีชิ้นเดียวแล้วการ์ดรกเกินไป)
- [x] แสดงเป็นแถวใต้กลุ่มไทล์ พร้อมชื่อสี + hex + เหตุผล สวอตช์เส้นประ = ยังไม่ใช่ของจริงในตู้
- [x] หมวดที่มีชิ้นเดียวยัง disabled + hint เดิม (ไม่แตะพฤติกรรมตาม spec §7C)
