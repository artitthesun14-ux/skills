# 06: Swap ใช้ได้ทุกการ์ดในแบตช์

**What to build:** ผู้ใช้ปรับชุดทีละชิ้นได้กับทุกชุดในแบตช์ ไม่ใช่เฉพาะการ์ดที่โฟกัสอยู่

**Blocked by:** None (can start immediately).

**Status:** blocked-needs-decision

- [ ] **ติดปัญหาเชิงออกแบบ ต้องให้ผู้ใช้ตัดสินก่อน:** การ์ดข้างๆ ใน carousel โผล่แค่ 40-72px (peek)
      และถูกตั้งเป็น `aria-hidden="true" inert` ตั้งแต่เฟส 1 เพื่อ a11y ปุ่มสลับบนการ์ดนั้นจึงทั้ง
      กดไม่ถึงจริง (ถูก clip) และขัดโมเดล a11y ของ carousel เดิม
- [ ] อีกด้านหนึ่ง "สลับได้ทุกชุด" ทำได้อยู่แล้ววันนี้ผ่านการกด `<` `>` ไปที่ชุดนั้นแล้วสลับ
- [ ] ทางเลือกที่ต้องเลือก: (ก) ถือว่าข้อนี้ได้ตามเป้าหมายแล้ว ปิดตั๋ว (ข) เปลี่ยนเป็น "แตะการ์ดข้างๆ
      แล้วเลื่อนมาโฟกัสทันที" (ลดขั้นตอนจริง ไม่ขัด a11y) (ค) ออกแบบ carousel ใหม่ให้การ์ดข้างๆ
      กดใช้งานได้จริง (งานใหญ่ ผูกกับเฟส D)
