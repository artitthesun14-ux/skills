# 06: Swap ใช้ได้กับทุกชุดในแบตช์

**What to build:** ผู้ใช้ปรับชุดทีละชิ้นได้กับทุกชุดในแบตช์ ไม่ใช่เฉพาะชุดเดียว

**Blocked by:** None (can start immediately).

**Status:** done (เฟส 4-B)

ผู้ใช้เลือกทางออก (2026-09-13): **แตะการ์ดข้างๆ แล้วเลื่อนมาโฟกัสทันที** แทนการทำให้ปุ่มบนการ์ด
ข้างๆ กดได้เอง เพราะการ์ดข้างๆ โผล่แค่ 40-72px และเป็น `inert` + `aria-hidden` มาตั้งแต่เฟส 1

**บั๊กจริงที่เจอตอนลงมือ:** ปุ่มสลับถูกเรนเดอร์ให้เฉพาะการ์ดที่โฟกัส *ตอนเรนเดอร์* แต่การเลื่อนการ์ด
(`updateCarousel()`) สลับแค่คลาส ไม่ได้เรนเดอร์ใหม่ ผลคือเลื่อนไปชุดที่ 2 แล้ว **ไม่มีปุ่มสลับเลย**
มาตั้งแต่เฟส 2 นี่คือสิ่งที่ผู้ใช้เจอจริงตอนบอกว่า "ใช้ได้แค่การ์ดเดียว" ไม่ใช่เรื่อง peek

- [x] แตะการ์ดที่ยังไม่โฟกัส -> การ์ดนั้นเลื่อนมาโฟกัส (ปุ่มโปร่งทับ slot, `tabindex="-1"` เป็น pointer-only)
- [x] ปัดนิ้วแล้ว click ที่ตามมาไม่ทำให้กระโดดการ์ดซ้ำ
- [x] ปุ่มสลับเรนเดอร์ให้ทุกการ์ดในโหมดตู้ แล้วให้ CSS ซ่อนบนการ์ดที่ยังไม่โฟกัส -> เลื่อนไปชุดไหนก็สลับได้ทันที
- [x] การ์ดข้างๆ ยังเป็น `inert` + `aria-hidden` เหมือนเดิม คีย์บอร์ดยังใช้ `<` `>` และลูกศรซ้าย-ขวา
- [x] เทสต์ TF1-TF5 ใน `ac-test.js`
