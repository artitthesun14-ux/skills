# 14: รีดีไซน์การแสดงผลชิ้นเสื้อผ้าเป็น Collage Art Style

**What to build:** การ์ดแนะนำและตู้เสื้อผ้าใช้ภาษาภาพเดียวกัน: ทรงเสื้อผ้าซ้อนทับแบบตัดแปะ
มีเงาทึบ+ขอบกระดาษ ป้ายทั้งหมดย้ายออกจากตัวทรงไปอยู่ใน legend แถบเดียวใต้กลุ่มทรง

**Blocked by:** 12 (ต้องมีโทเคนก่อน)

**Status:** done (เฟส 4-D)

- [x] tile ในการ์ดซ้อนทับกันไม่เกิน `--collage-overlap-max` หมุนตาม `--collage-rotate-N` ตามตำแหน่ง
- [x] `CollageLegend` ใต้กลุ่มทรง: สวอตช์ + ชื่อหมวด + ชื่อทรง/ชื่อชิ้น + ชื่อสี + hex ครบทุกชิ้น
- [x] หมวดที่ไม่มีของไม่กินตำแหน่งในสแตก (มี 2 ทรงก็ใช้แค่ 2 มุมแรก)
- [x] ปุ่มสลับทีละชิ้นยังกดได้ ไม่ถูกทรงอื่นทับ และยังผ่านเกณฑ์ touch target 44px
- [x] `GarmentChip` ในตู้ใช้เงา/ขอบชุดเดียวกัน (ทรงเดี่ยว ไม่ซ้อน)
- [x] ไม่แตะ registry ทรง (`shapeId` permanence) เลย
