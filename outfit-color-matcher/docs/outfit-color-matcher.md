# โปรเจกต์: เว็บไซต์จับคู่สีเสื้อผ้า / แนะนำชุดจากตู้ (Outfit Color Matcher)

> สรุปโปรเจกต์ (ยังไม่ลงมือสร้าง) ใช้เป็นสเปกตั้งต้นสำหรับสร้าง **เว็บไซต์** (artifact หน้าเว็บเดียว) ในภายหลัง
> เวอร์ชันนี้รวมข้อสรุปหลังการ Grill แล้ว (จุดที่ชัดเจนถูกเขียนลงในแต่ละหัวข้อ)
> เริ่มสร้างเมื่อพิมพ์ "เริ่มได้เลย"

## 1. เว็บไซต์นี้คืออะไร
**เว็บไซต์** ช่วยแต่งตัว ที่เป็นฝ่าย **แนะนำชุดให้ทันที** จากเสื้อผ้าในตู้ของคุณ (สีเข้ากัน) แทนที่จะให้คุณเลือกทีละชิ้นเอง
เป็นเว็บหน้าเดียว (single-page website) เก็บข้อมูลในเครื่อง เปิด/แชร์ลิงก์ได้ ไม่ต้องล็อกอิน ไม่ต้องติดตั้ง

## 2. การตัดสินใจหลัก (จากที่คุยกัน + หลัง Grill)
1. **หน้าที่แรก = แนะนำชุดให้เลย** (ไม่ใช่ให้ผู้ใช้จับคู่เองก่อน)
2. **ทำทั้งสองอย่าง:** (A) แมทเสื้อผ้าจริงในตู้ + (B) สร้างชุดโทนสีสวยเป็นไอเดีย
3. **เสื้อผ้าสีเดียว ไม่มีลาย** มองแต่ละชิ้นเป็น 1 สี
4. **สีเข้าเว็บโดย: ดึงจากรูป (canvas) + แก้ค่าสีเองได้**
5. **[หลัง Grill] ไม่ให้คะแนน ไม่ตัดสิน/วิจารณ์การแต่งตัว** แต่ให้ **คำแนะนำอิงทฤษฎีสี + ตัวเลขบอกสัดส่วนสีของลุค** แทน (จุดเปลี่ยนใหญ่: ตัด "Match Score" ทิ้ง)

## 3. สถาปัตยกรรม: Color Matching Engine เป็นแกนกลางเดียว
หัวใจสำคัญ: ทุกฟีเจอร์ใช้ **เครื่องยนต์จับคู่สีชุดเดียวกัน** ไม่ได้สร้างระบบใหม่แยกกันหลายชุด
แต่ละฟีเจอร์แค่ตั้ง "เงื่อนไข (constraint)" ต่างกัน แล้วส่งให้ engine ตัวเดิมทำงาน:

- **Input (เงื่อนไข):** หมวดที่ต้องมี / สีหลักที่ล็อก / ชิ้นที่ล็อก / โอกาส / สไตล์ / โทนสี
- **สิ่งที่ engine ทำ:** (1) หา combination ของเสื้อผ้าข้ามหมวด → (2) **คำนวณความกลมกลืนเงียบๆ เบื้องหลัง** ตาม 5 harmony rules + ความต่างสว่าง/อิ่ม + สัดส่วนสีกลาง (ใช้เพื่อ**คัดและเรียง** ว่าจะโชว์ชุดไหนก่อน **แต่ไม่แสดงเป็นเกรด/คะแนนให้ผู้ใช้เห็น**) → (3) จัดสัดส่วนสีของลุค → (4) เลือกคำแนะนำ (template) อิงทฤษฎีสี
- **Output ต่อชุด:** ชิ้นเสื้อผ้าที่จับคู่ + **สัดส่วนสีแบบ 60-30-10 (หลัก/รอง/เน้น) + % รายสี** + **คำแนะนำอิงทฤษฎีสี** (ไม่มีตัวเลขคะแนนความดี-ด้อย)

## 4. ฟีเจอร์ทั้งหมด (7 ฟีเจอร์ + ตู้เสื้อผ้า)

### ฐาน: ตู้เสื้อผ้า (Wardrobe)
- เพิ่ม/แก้/ลบชิ้นเสื้อผ้า (ชื่อ, หมวด, สี hex, รูปถ้ามี) แสดงเป็นชิปสี
- **ดึงสีจากรูป:** อัปโหลดรูป → ย่อด้วย canvas → **เฉลี่ยสีโซนกลางภาพ (เลี่ยงพื้นหลัง/ขอบ)** → เติมช่องสีที่ **แก้ hex เองได้เสมอ** (ถือรูปเป็นตัวช่วย ไม่ใช่ตัวตัดสิน แม่นระดับ "พอใช้" พอ)

### 1. Today Outfit "วันนี้แต่งอะไรดี?" (พระเอก)
กดปุ่ม → เลือกโอกาส (Everyday / University / Work / Cafe / Dinner / Party / ไม่ระบุ) → engine ดูตู้ → สร้างชุดที่เป็นไปได้ → คัด/เรียงเงียบๆ เบื้องหลัง → โชว์ **Top 3** (โชว์เท่าที่จับคู่ได้ถ้าไม่ถึง 3) แต่ละชุดมี **สัดส่วนสี 60-30-10 + % รายสี** และ **คำแนะนำอิงทฤษฎีสี** เช่น "โทนนี้เป็น analogous สีใกล้เคียงกัน ดูกลมกลืน", "มีสีกลางคุมโทน 2-3 สี", "รองเท้าสีอ่อนช่วยให้ลุคดูเบา"
- **โอกาส มีผลกับการปรับโทนสีเท่านั้น** (Work/Dinner เอนโทนเข้ม/สีกลาง, Party ยอม accent จัดขึ้น, Everyday/Cafe โทนสบายกลางๆ) ไม่แสร้งรู้ความเป็นทางการของเสื้อผ้าจริง
- **ปุ่ม Generate = หมุนไปชุดถัดไป** ที่เข้ากัน (ไล่เท่าที่มี ไม่สุ่มซ้ำของเดิม)
- **Acceptance:** ได้ชุดอย่างน้อย 1 ชุดถ้าเสื้อผ้าพอ; ใช้เสื้อผ้าจริงจาก Wardrobe; **ชุดครบต้องมี บน+ล่าง เป็นอย่างน้อย** (ที่เหลือเสริม) ห้ามโชว์ชุดที่ขาดหมวดจำเป็น; โชว์สัดส่วนสี + คำแนะนำ; Generate หมุนชุดถัดไปได้; ถ้าตู้ไม่พอให้ชวนเพิ่มชิ้นที่ขาดแทนการแนะนำมั่ว

### 2. Swap One Item "เปลี่ยนแค่ชิ้นเดียว"
เมื่อชอบชุด แต่ไม่ชอบบางชิ้น ไม่ต้องสร้างใหม่หมด ระบบ **ล็อกชิ้นอื่นไว้** แล้วเปลี่ยนเฉพาะชิ้นเดียว
- ปุ่ม: 🔄 เปลี่ยนเสื้อ / 🔄 เปลี่ยนกางเกง / 🔄 เปลี่ยนรองเท้า / 🔄 เปลี่ยน Outerwear
- **สลับทีละตัว วนได้:** กดหนึ่งครั้งได้ตัวถัดไปที่เข้ากันดีในหมวดนั้น (ตามการคำนวณเงียบเบื้องหลัง) กดซ้ำวนตัวถัดไปเรื่อยๆ

### 3. Favorite Outfit
บันทึกชุดที่ชอบไว้ใน localStorage แต่ละชุดทำได้: ❤️ Save / 🗑 Delete / ✏️ ตั้งชื่อ / 📋 Duplicate / 🔄 เปิดแก้ไข

### 4. Wardrobe Color Analysis "ตู้เสื้อผ้าของฉัน" (จุดต่างของเว็บ)
วิเคราะห์สีของเสื้อผ้าทั้งตู้
- สัดส่วนสี (%) เช่น Black 32% / White 21% / Beige 18% ...
- แยกกลุ่ม: Neutral vs Accent, และ Color Diversity (Neutral / Cool / Warm / Accent) **โดยจัดกลุ่มจากค่า HSL อัตโนมัติ** (อิ่มสีต่ำ = neutral)
- **insight + "สีที่ช่วยเพิ่มการจับคู่" สร้างจากกฎ threshold + ข้อความสำเร็จรูป** เช่น neutral > 70% → "ตู้คุณโทนสงบมาก ลองเพิ่ม accent 1 สีเพื่อเพิ่มลุค"; **สีที่แนะนำ = สีที่เข้ากับสีฐานที่มีมากสุดในตู้ (ตามกฎสี) แต่ยังขาดในตู้** เขียนเชิง "เพิ่มตัวเลือกการจับคู่" ไม่ใช่บอกให้ไปซื้อ
- **Acceptance:** วิเคราะห์จาก garments ใน Wardrobe; โชว์จำนวน+สัดส่วน; แยก Neutral/Color/Accent ได้; insight อย่างน้อย 1-3 ข้อ; ถ้าข้อมูลน้อยเกินไปต้องบอกผู้ใช้แทนวิเคราะห์มั่ว

### 5. "วันนี้อยากใส่สีอะไร?" (color-first)
ผู้ใช้อยากนำสีเอง เลือกสี (จาก swatch หรือจากสีจริงในตู้) → ล็อกเป็น Main Color → engine หา bottom/shoes ที่เข้า → คัด/เรียงเงียบเบื้องหลัง
- ตัวอย่างผล (แสดงเป็นสัดส่วนสี ไม่ใช่คะแนน): Navy + Cream + White · Neutral 70% / Accent 30% · "โทน monochrome เย็น ดูสะอาด"

### 6. Outfit Generator (เล่นสนุก + หา inspiration)
ต่างจาก Today Outfit ตรงที่สร้างชุดตาม **Style / Color** ที่ผู้ใช้กำหนด ไม่ผูกกับ "วันนี้"
- เลือก Style: Minimal / Casual / Smart Casual / Street / Classic / Monochrome ...
- เลือก Color: Random / Neutral / Warm / Cool / Dark / Light
- สวิตช์ "Use my wardrobe":
  - **Mode A** (ติ๊ก): สร้างจาก garment จริงในตู้
  - **Mode B** (ไม่ติ๊ก): **สร้าง Color Palette ไอเดียจากกฎสีสดๆ** (สุ่มสีตั้งต้นตาม Color filter → ดึงสีตาม rule → จัดสัดส่วน 60-30-10) เช่น LOOK #01: Beige / Black / White / Olive

### 7. รวมเป็นระบบเดียว
ทั้งหมดแชร์ Color Matching Engine + Wardrobe + โมเดล Outfit ชุดเดียว ตาม Core UX ข้อ 3 (ไม่ทำเป็นปุ่ม 7 ปุ่มแยกเต็มหน้า)

## 5. โมเดลข้อมูล (ร่าง)
- **Garment:** `{ id, name, category, color(hex), photo?(data URL) }`
- **Category:** บน / ล่าง / นอก / รองเท้า / แอกเซสซอรี (**ชุดครบ = ต้องมี บน+ล่าง**, ที่เหลือเสริม)
- **Occasion:** everyday / university / work / cafe / dinner / party / unspecified (**map เป็นการปรับโทนสีเท่านั้น**: โทนสว่าง/มืด, ความจัดของ accent)
- **Style / ColorMood:** ตัวกรอง input ของ Outfit Generator (Mode B ใช้สร้าง palette)
- **Outfit (ผลลัพธ์):** `{ items:{top,bottom,outer?,shoes?,accessory?}, proportion:{main,secondary,accent}, colorBreakdown:[{hex,pct}], ruleUsed, advice:[...], _harmony (ภายใน ไม่โชว์) }`
  - **role 60-30-10 กำหนดตามหมวด:** บน+ล่าง = สัดส่วนหลัก (60), นอก = รอง (30), รองเท้า/แอกเซสซอรี = เน้น (10) แล้วรวมสีตามน้ำหนักหมวด
- **SavedOutfit:** `{ id, name, items, proportion, ruleUsed, createdAt }` เก็บใน localStorage
- **Wardrobe analysis:** จัดกลุ่ม hue จาก HSL → warm/cool/neutral/accent, สัดส่วน, diversity, insights (threshold + template)
- เก็บตู้ + Favorites ทั้งหมดใน **localStorage** (ต่อเครื่อง/เบราว์เซอร์)

## 6. เทคนิค/ข้อจำกัด
- เว็บหน้าเดียว self-contained, **ไม่ใช้ capability ใดๆ** (localStorage ล้วน) → แชร์สาธารณะได้; คำแนะนำใช้ **template ล้วน ไม่เรียก AI ตอบสด**
- ดึงสี + ย่อรูป ทำ client-side ด้วย canvas (ไม่โหลดไลบรารี/รูปจากภายนอก ให้ผ่าน CSP)
- รูปเก็บเป็น data URL แบบย่อ (สูงสุด ~2 รูป/ชิ้น กัน localStorage เต็ม)
- นิยาม neutral: ค่าอิ่มสี (S) ต่ำกว่า ~15-20% ใน HSL = neutral (ค่าตั้งต้น ปรับจูนได้จากผลจริง)
- ธีมสว่าง/มืด, responsive, a11y: **ไม่สื่อด้วยสีอย่างเดียว** (โชว์ชื่อสี/ค่า hex/ชื่อ rule/สัดส่วนกำกับ)

## 7. แผนสร้างแบบแบ่งเฟส (3 เฟส เพื่อไม่ให้งานหนักเกิน)
> แต่ละเฟสจบแล้วได้เว็บที่ใช้งานได้จริง เผยแพร่/ส่งไฟล์ได้ ไม่ต้องรอครบทั้งหมด

### เฟส 1: แกนหลัก (ได้ของใช้ได้เร็วที่สุด)
- ตู้เสื้อผ้า: เพิ่ม/แก้/ลบ + ดึงสีจากรูป + แก้ hex + ชิปสี (localStorage)
- **Color Matching Engine** (hex→HSL, คำนวณความกลมกลืนเงียบเบื้องหลัง, 5 harmony rules, สัดส่วน 60-30-10, คำแนะนำ template)
- **Today Outfit "วันนี้แต่งอะไรดี?"**: เลือกโอกาส → Top 3 + สัดส่วนสี + คำแนะนำ + Generate หมุนชุดถัดไป
- seed เสื้อผ้าตัวอย่าง (ติดป้าย "ตัวอย่าง") + ปุ่มล้างตัวอย่าง ให้เห็นผลทันทีตอนเปิดเว็บ
- ดีไซน์ฐาน (สีแบบ Rand: สีแบน คอนทราสต์ชัด) + light/dark + a11y

### เฟส 2: ต่อยอดจากผลลัพธ์
- **Swap One Item**: ล็อกชิ้นอื่น เปลี่ยนทีละชิ้น วนได้ (เสื้อ/กางเกง/รองเท้า/Outerwear)
- **Favorite Outfit**: Save / ตั้งชื่อ / Delete / Duplicate / เปิดแก้ไข (localStorage)

### เฟส 3: ทางเข้าเสริม + วิเคราะห์
- **"วันนี้อยากใส่สีอะไร?"** (color-first): ล็อก main color → หาชุดรอบสีนั้น
- **Outfit Generator**: Style + Color + Mode A (ตู้จริง) / Mode B (palette จากกฎสีสดๆ)
- **Wardrobe Color Analysis**: สัดส่วนสี + Neutral/Accent + diversity + insight (threshold+template) + "สีที่ช่วยเพิ่มการจับคู่"
