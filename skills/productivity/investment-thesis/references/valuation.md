# Valuation

Ask **what expectations today's price embeds**, then judge whether the thesis meets them. A multiple alone answers neither.

## Reverse-engineer the price

Work from the current market value (enterprise value, with net debt and the date stated) back to the assumptions it requires:

```
Price → revenue path → margin path → growth duration → FCF → terminal assumptions
```

A simple reverse DCF is enough: solve for the revenue growth and steady-state margin that justify today's value at a stated discount rate. Show the inputs so the user can change them.

## Traps

- A low P/E can reflect peak earnings in a cyclical. Normalise across the cycle first.
- A high P/E can be cheap if incremental ROIC is high and growth is long.
- Compare multiples only with peers at the same value chain stage.

End with one sentence: **"For today's valuation to make sense, X, Y and Z must be true."**
