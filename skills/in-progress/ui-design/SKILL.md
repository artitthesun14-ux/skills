# UI Design

Turn a validated UX flow into a UI that's usable, consistent, and ready to build: a system of reusable components, not one-off screens.

## Workflow

1. Define visual hierarchy and layout.
2. Establish typography, spacing, sizing, and component rules.
3. Design reusable components rather than one-off screens.
4. Define responsive behavior for the relevant breakpoints.
5. Define every important component state.
6. Check contrast, readability, touch targets, and accessibility.
7. Check consistency across screens.
8. Produce implementation-ready UI specifications.

## Output

- Screen-by-screen UI description
- Layout hierarchy
- Component inventory
- Design tokens
- Responsive rules
- Component states
- Accessibility notes
- Visual rationale

## Rules

- Reuse components and patterns; don't invent a new one where an existing one fits.
- Avoid arbitrary styling decisions that can't be explained.
- Keep content hierarchy obvious.
- Design for real data, not only ideal placeholder content.
