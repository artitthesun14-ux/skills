# Experiment

Compare alternatives by evidence instead of guessing which version is better.

## Core loop

Hypothesis → change → run → measure → compare → keep/reject → record → repeat.

## Workflow

1. Define one clear hypothesis.
2. Define the metric and success threshold before running anything.
3. Change as few variables as practical.
4. Run the experiment under repeatable conditions.
5. Collect results and any relevant qualitative feedback.
6. Compare against a baseline or alternative.
7. Keep, reject, or iterate based on the evidence.
8. Record the result so future work doesn't repeat a failed approach.
9. Stop when improvement is marginal, the target is met, or the evidence is sufficient.

## Output

- Hypothesis
- Baseline
- Variant/change
- Metric
- Experimental conditions
- Results
- Decision
- Learning
- Next experiment

## Rules

- Never manufacture metrics.
- Distinguish measured results from subjective judgment.
- Avoid changing many variables at once when causality matters.
- Preserve successful versions and document failed approaches.
