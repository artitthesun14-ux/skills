# UI Design

## Purpose

Turn a validated UX into a UI that is attractive, usable, consistent, and ready to build into code.

## Workflow

1. Define visual hierarchy and layout.
2. Establish typography, spacing, sizing, and component rules.
3. Design reusable components rather than one-off screens.
4. Define responsive behaviour for relevant breakpoints.
5. Define all important component states.
6. Check contrast, readability, touch targets, and accessibility.
7. Check consistency across screens.
8. Produce implementation-ready UI specifications.

## Output

- Screen-by-screen UI description
- Layout hierarchy
- Component inventory
- Design tokens
- Responsive rules
- Component states
- Accessibility notes
- Visual rationale

## Rules

- Reuse components and patterns.
- Avoid arbitrary styling decisions that cannot be explained.
- Keep content hierarchy obvious.
- Design for real data, not only ideal placeholder content.
