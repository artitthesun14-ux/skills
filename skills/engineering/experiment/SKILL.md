# Experiment

## Purpose

Use an experimental loop to compare alternatives and improve what was built from evidence, instead of guessing which version is best.

## Core Loop

Hypothesis, Change, Run, Measure, Compare, Keep/Reject, Record, Repeat.

## Workflow

1. Define one clear hypothesis.
2. Define the metric and success threshold before the experiment.
3. Change as few variables as practical.
4. Run the experiment using repeatable conditions.
5. Collect results and relevant qualitative feedback.
6. Compare against a baseline or alternative.
7. Keep, reject, or iterate based on evidence.
8. Record the result so future work does not repeat failed experiments.
9. Stop when improvement is marginal, the target is met, or evidence is sufficient.

## Output

- Hypothesis
- Baseline
- Variant/change
- Metric
- Experimental conditions
- Results
- Decision
- Learning
- Next experiment

## Rules

- Never manufacture metrics.
- Distinguish measured results from subjective judgment.
- Avoid changing many variables at once when causality matters.
- Preserve successful versions and document failed approaches.
