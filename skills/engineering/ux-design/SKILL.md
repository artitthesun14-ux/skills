# UX Design

## Purpose

Design the user experience before any UI detail, so users can reach their goal easily and clearly, with a path through abnormal states.

## Workflow

1. Identify primary user goals.
2. Map the end-to-end user journey.
3. Design information architecture and navigation.
4. Define core flows and alternative flows.
5. Define empty, loading, success, error, offline, permission, and destructive states where relevant.
6. Check accessibility and usability.
7. Resolve UX issues against the product spec.
8. Produce a screen/state map for `ui-design`.

## Output

- User journey
- Information architecture
- Screen map
- Primary/alternative flows
- Interaction rules
- System states
- Accessibility considerations
- UX decisions and rationale

## Rules

- Optimise for user clarity before visual decoration.
- Minimise unnecessary steps.
- Every important action should have understandable feedback.
- Do not design screens that are not supported by the product requirements without labelling them as proposals.
